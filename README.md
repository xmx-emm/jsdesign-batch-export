# 即时设计 · 批量导出预设插件

选中图标（或包含图标的画板 / 编组）→ 点一下预设的「导出」→ 所有图标按预设的尺寸和格式导出，打包成一个 ZIP 下载。

## 安装（本地开发插件）

1. 打开即时设计（桌面客户端或网页版），进入任意设计文件。
2. 主菜单 → 插件 → 开发者 → 导入插件，选择本目录下的 `manifest.json`。
3. 之后在 插件 → 开发者 里就能运行「批量导出预设」。

不需要构建，`code.js` / `ui.html` 可以直接用。

## 用法

- **选中范围**：勾选「导出其内部每个子图层」后，选中一个画板会导出画板里的每个可见子图层（适合一个画板里排满图标的情况）；不勾选则导出选中的图层本身。
- **预设**：一个预设可以包含多行「格式 + 尺寸」，例如 PNG @1x / @2x / @3x。
  - 尺寸方式：倍率（SCALE）/ 固定宽度（WIDTH）/ 固定高度（HEIGHT），只对 PNG、JPG 生效；SVG、PDF 按原尺寸导出。
  - 文件名后缀：加在图层名后面，比如 `@2x`。
  - 子文件夹：ZIP 内的目录，比如 Android 的 `drawable-xhdpi`。
  - 文件名格式：保持原名 / 小写 / kebab-case / snake_case。
- **按图层自带导出设置导出**：使用每个图层右侧「导出」面板里已经配置的设置。
- **导入 / 导出预设**：复制 JSON 备份或分享给同事，粘贴后点「应用」导入。
- 预设保存在 `clientStorage`（本机），换电脑需要用「导入 / 导出预设」迁移。
- 重名文件会自动加 `_2`、`_3` 后缀，不会被覆盖。

## 文件

- `manifest.json`：插件描述。`id` 为 `mx-jsdesign-batch-export`；如果发布到插件市场时平台分配了新的 id，以平台为准。
- `code.js`：主线程，读取选区、调用 `exportAsync`、读写预设。
- `ui.html`：面板 UI，内置无依赖的 ZIP 打包（不压缩，PNG/SVG 本身已压缩，影响很小）。
